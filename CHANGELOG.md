# Changelog

### Added

- Verified one-click installation of Hysteria 2 `v2.12.1` on Linux amd64 and arm64.

- One-time user credentials, certificate-pinned connection URIs, traffic statistics and connection kicking.
- Hardened systemd services, consistent upgrade backups and health checks.
