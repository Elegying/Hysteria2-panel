# 术语表

| 术语 | 通俗解释 |
|---|---|
| 中央面板 | 管理用户、节点、配额和状态的 Hysteria2-panel 实例 |
| 面板本机节点 | 与中央面板安装在同一台服务器上的 Hysteria 数据入口 |
| 数据节点 | 通过签名协议接入中央面板的其他 Hysteria 服务器 |
| 数据面 | 真正承载用户 Hysteria/QUIC 流量的服务和端口 |
| 控制面 | 用户鉴权、在线快照、流量 ACK、节点命令和状态管理 |
| 客户端实例 | Hysteria `/online` 统计的一次在线客户端，不等同于物理设备 |
| 主入口 | 默认 UDP `19999` 的 Hysteria 服务 |
| 账号专属入口 | 默认 UDP `443` 的第二个 Hysteria 服务，仅允许已授权账号 |
| TCP 兼容探测 | 接受 TCP 连接后立即关闭的探测端口，不承载 Hysteria 数据 |
| `FULL` | 允许全部公网目标的出站策略，风险和兼容性都更高 |
| `WEB` | 主要允许网页、视频、DNS、NTP 和公网 SSH 的受限策略 |
| 在线快照 | 数据节点定期提交的当前用户实例数 |
| 流量 ACK | 中央面板确认某个流量批次已经持久入账 |
| durable spool | 数据节点在中央暂不可达时保存未确认流量批次的持久目录 |
| 摘流 | 节点继续服务已有流量，但开始从 DNS 或入口中移除的阶段 |
| 安全停用 | DNS 已删除、设备归零且流量 ACK 新鲜后停止数据面 |
| 安全重绑定 | 同一台已部署节点保留私钥、证书和 spool，重新连接中央面板 |
| canary | 先对一台低风险节点升级并验收，再继续整个批次 |
| 失败关闭 | 无法确认安全状态时拒绝新认证，而不是默认放行 |
| Hysteria TLS | 用户数据入口的长期节点证书，指纹固定在分享 URI 中 |
| 面板 TLS | 管理网页使用的独立 HTTPS 证书，通常由 Let’s Encrypt 管理 |
| Sigstore | 用 GitHub Actions OIDC 身份验证正式发布文件来源的签名机制 |
| SBOM | 正式版本所含源码文件与哈希的机器可读清单 |
