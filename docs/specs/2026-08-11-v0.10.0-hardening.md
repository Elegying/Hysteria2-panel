# v0.10.0 认证、网络与部署加固规格

## 范围

本版本只改变面板缺省访问协议、管理员登录防护、服务端网络调优、安装器兼容性和文档。用户数据模型、Hysteria 分享 URI、备份格式版本和恢复连续性保持兼容。

## 验收标准

### 面板协议

1. 未提供 `PANEL_SCHEME` 时，交互提示显示 `[http]`，直接回车写入 `http`。
2. 未提供 `HY2PANEL_PANEL_SCHEME` 时，应用默认按 HTTP 启动。
3. 显式选择 `https` 时继续加载现有 Hysteria TLS 证书供面板使用。
4. 面板协议变化不得修改 Hysteria 证书、私钥、指纹或用户分享 URI。

### 登录防破解

1. 每个来源 IP 独立统计 15 分钟观察窗口内的错误登录。
2. 第 1 至第 4 次错误返回通用 `401`；第 5 次错误立即返回 `429` 并锁定 15 分钟。
3. 锁定期间即使提交正确密码也不得登录；响应带整数秒 `Retry-After`。
4. 观察窗口到期后解锁；成功登录清除该来源之前的失败记录。
5. 内存中的来源记录有固定上限；审计记录登录失败、锁定和成功，不记录账号密码。
6. 不存在的账号仍执行一次等价的 scrypt 校验，避免明显的用户名时序枚举。

### 网络优化

1. 生成的 Hysteria 配置包含 `congestion.type: bbr`、`bbrProfile: standard` 和 `ignoreClientBandwidth: true`。
2. 项目 sysctl 文件将 `rmem_max/wmem_max` 提升到至少 16 MiB，已有更高值保持不变。
3. 内核提供 BBR 时写入并应用 `net.core.default_qdisc=fq` 与 `net.ipv4.tcp_congestion_control=bbr`；不提供时输出说明但部署继续。
4. Hysteria systemd 单元设置 `Nice=-5`、高文件描述符上限和现有资源/安全边界。
5. 不自动添加防火墙规则，不伪造 ping 或延迟值。

### 安装兼容

1. 支持 Linux amd64/arm64、systemd、Python 3.8+。
2. 自动安装依赖支持 apt、dnf 和 yum；未知包管理器明确列出缺失命令后停止。
3. RHEL 8 系默认 Python 过旧时尝试可用的 Python 3.9，再次验证版本。
4. 下载官方 Hysteria 和项目运行文件后均执行完整性或语法校验。
5. 重复运行不覆盖非项目托管路径，不降低现有 socket 缓冲，不轮换持久身份。

### 文档与发布

1. GitHub 可见文档统一使用中文，命令、路径和协议字段保留原文。
2. README 明确 HTTP 风险、支持系统、5 次锁定、BBR 边界、回滚和真机验收步骤。
3. 版本提升到 `0.10.0`，变更日志区分安全、优化、修复和兼容性。
4. 所有自动化检查通过后才发布；真机 YouTube 和海外网页体验由用户验收，不用自动化结果替代。

## 明确不做

- 不增加 CAPTCHA、邮件解锁、MFA 或外部认证依赖。
- 不把面板 HTTP 描述为安全链路，也不把 TCP 探测当作 Hysteria 健康证明。
- 不自动估算带宽并开启 Brutal，不使用未经官方说明的“魔法 sysctl”参数。
- 不修改备份格式，不重签 10 年节点证书，不重新分享现有节点。
