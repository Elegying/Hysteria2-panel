# v0.32.0 节点运营规格

## 目标

在不修改任何用户 URI、域名、端口、token、Hysteria 长期证书或证书 pin 的前提下，
让管理员可以在一个面板里完成四件事：

1. 分别查看并设置面板本机、每个对接节点的自然月流量预算；
2. 在达到阈值时看到明确告警；
3. 用向导安全摘流、停用、恢复或更换数据节点；
4. 每天生成一次可迁移备份，并在配置 HTTPS WebDAV 后异地保存 30 天。

## 不可破坏的兼容边界

- 用户仍然直接连接 DNS 选中的 Hysteria 节点，不经过面板中转。
- 全局用户流量和设备上限继续由中央面板统一判定。
- 不自动修改 DNS，不自动轮换 Hysteria 证书，不改用户配置。
- 节点停用保留 Ed25519 私钥、Hysteria TLS 身份和 durable traffic spool。
- 所有节点命令必须是固定枚举和固定参数，禁止下发 shell。

## 1. 分机器月度预算

### 记账

- 面板本机和每个远端节点都使用现有稳定 `origin_id`。
- 新增按 UTC 日期聚合的增量账本。每次本地流量提交或远端幂等 batch 首次提交时，
  在同一 SQLite 事务内增加当日上传和下载；重复 batch 不重复记账。
- 自 v0.32.0 首次产生增量后开始统计，不把升级前累计量伪装成本月用量。
- “重置用户流量”只重置账号配额计数，不清空机器本月已发生的带宽预算用量，避免通过
  重置账号把服务器供应商已经计费的流量抹掉；历史累计来源归属仍遵守原有行为。

### 预算与告警

- 每个来源可独立启用或关闭预算，单位为 GiB；默认关闭。
- 告警阈值可设为 1–99%，默认 80%。状态为：正常、接近预算、已用尽。
- 告警首先在 Dashboard 的分机器表和 Prometheus 汇总指标中可见；本版本不声称提供
  邮件、短信或聊天机器人推送。
- 达到预算不会自动停节点，避免无人值守时把仍在 DNS 中的节点突然断开；管理员可进入
  一键摘流向导处理。

## 2. 摘流、停用、恢复和换机

### 生命周期

远端节点新增 `active -> draining -> stopping -> stopped -> starting -> active` 生命周期。
`archived` 仅隐藏已完成换机的旧节点，但保留来源统计和审计记录。

### 安全摘流

1. 管理员点击“开始摘流”，节点仍接受认证，避免 DNS 尚未生效时中断用户。
2. 管理员手工从用户域名的 A/AAAA 中移除该节点 IP。
3. 面板只读确认 DNS 已无该 IP、节点新鲜在线数为 0、最后流量已 ACK。
4. 面板向节点下发固定 `STOP_DATA_PLANE` 命令；节点先结算 durable spool，再停止两路
   Hysteria 服务，Agent 保持运行并 ACK，中央随后标记 `stopped`。

任何门禁未满足时都不误报停用成功。紧急停用跳过 DNS/在线门禁，但 UI 必须说明旧 DNS
命中的用户会失败。

### 恢复与换机

- “恢复节点”下发固定 `START_DATA_PLANE`，成功后回到待 DNS 准入状态；管理员添加 DNS，
  现有只读 DNS 监控完成准入。
- “更换服务器”在旧节点完成停用后，让替换服务器走“全新节点对接”；它取得面板备份
  中的同一 Hysteria TLS 长期身份，不改变用户配置。旧节点 Ed25519 私钥和已排空 spool
  原样留在旧机，替换节点加入 DNS 后才能归档旧记录。
- “安全重绑定”只用于已经部署的同一台数据节点重新连接当前/恢复后的面板；它复用原
  Ed25519 指纹并保留该机证书、数据面与 spool，不等同于把私钥隔空迁移到一台空白新机。
- 旧节点归档前必须已停止且无未完成命令。

## 3. 每日异地备份

- 安装器始终安装一次性 service 和每日 timer；随机延迟避免固定时刻拥塞。
- service 先调用现有备份管理器生成、自验证并原子公开 ZIP，再上传。
- 目标仅支持显式 `https://` WebDAV；配置和凭据保存在 root-only 文件，不进数据库、
  页面、日志、备份或 Git。
- 未配置时 timer 安全退出并写入脱敏状态 `not_configured`；面板显示“未配置”，不得显示
  为成功。
- 远端文件名使用项目固定前缀和 UTC 时间戳。上传使用临时名，完成后 WebDAV MOVE 到
  最终名；仅删除精确匹配且超过 30 天的本项目备份。
- HTTP、重定向到 HTTP、异常 PROPFIND 响应、尺寸不符或远端不支持原子 MOVE 时失败关闭，
  不执行保留清理。

## 4. 管理员向导

节点弹窗分成两组清晰的 1-2-3-4 步骤：

- 对接：生成命令 -> 新机执行 -> 核对指纹 -> 添加 DNS 并等待准入。
- 停用：开始摘流 -> 删除 DNS -> 等待归零并停用 -> 恢复、重绑或归档。

所有危险操作使用独立确认文案，移动端 320 px 不横向溢出，键盘和屏幕阅读器可完成。

## 验收标准

- 本机和远端首次/重复/跨日/跨月流量记账正确；预算状态可预测。
- 安全停用在 DNS 仍含节点、在线数非零、状态陈旧或 spool 未 ACK 时失败关闭。
- STOP/START 命令无任意执行面，失败可重试，重启后状态可收敛。
- WebDAV 未配置、失败、成功、30 天精确保留均有自动化测试。
- 安装、升级、恢复均包含新表、程序、unit、timer 和状态文件合同。
- 真实发布与部署前证明用户数、用户配置、长期证书/私钥、节点身份和 spool 不变。
