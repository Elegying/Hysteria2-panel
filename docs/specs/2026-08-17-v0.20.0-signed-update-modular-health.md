# Spec: v0.20.0 签名更新、模块化与健康探针

## Objective

在不改变节点身份、用户数据、认证协议和现有 `/healthz` 兼容行为的前提下：

1. 在线更新执行 root 安装器前，必须验证 GitHub Actions OIDC 身份签发并写入 Sigstore 透明日志的 Cosign bundle。
2. 按现有职责边界拆出版本、Web 静态资源、运维控制、更新和健康模块，降低 `hysteria2_panel.py` 的耦合与体积。
3. 区分进程存活与业务就绪，并提供只允许本机采集的无敏感信息指标。

## Tech Stack

- Python 3.8+ 标准库；不新增运行时 Python 依赖。
- Cosign 3.1.3 keyless blob signing 与 Sigstore bundle 验证。
- 现有 `http.server`、SQLite、systemd 与 unittest 测试体系。

## Commands

- 单元/集成测试：`python3 -m unittest discover -s tests -q`
- Python 编译：`python3 -m py_compile hysteria2_panel.py qrcodegen.py tcp_probe.py hy2panel/*.py`
- Python lint：`ruff check hysteria2_panel.py tcp_probe.py hy2panel tests`
- 安全扫描：`bandit -q -r hysteria2_panel.py tcp_probe.py hy2panel`
- 安装器语法：`bash -n install.sh`
- 安装器 lint：`shellcheck install.sh tests/firewall_integration.sh tests/systemd_integration.sh`

## Project Structure

- `hysteria2_panel.py`：兼容入口、数据/认证/HTTP 编排及高风险恢复主流程。
- `hy2panel/version.py`：包内版本来源。
- `hy2panel/web_assets.py`：CSS、JavaScript 与 favicon。
- `hy2panel/operations.py`：固定 systemd 操作、更新任务状态与系统指标。
- `hy2panel/release.py`：正式版检查、安装器下载和签名验证。
- `hy2panel/health.py`：线程、数据库与统计同步健康状态及 Prometheus 文本。
- `.github/workflows/release-signature.yml`：Release 发布后用短期 OIDC 身份自动签名并上传 bundle。

## Code Style

沿用无框架、显式依赖注入和固定 argv 的风格：

```python
result = runner(
    ["/opt/hysteria2-panel/bin/cosign", "verify-blob", installer_path],
    capture_output=True,
    text=True,
    timeout=10,
    check=False,
)
```

## Testing Strategy

- 先新增失败测试证明：缺失/篡改 bundle 被拒绝；`/healthz` 与 `/readyz` 语义不同；指标仅回环可读。
- Release 工作流签名后立即用真实 Cosign 验证，并验证修改一个字节后失败。
- 保留 276 项既有回归，补充模块导入与安装器固定哈希合同。
- 不以 mock 的“被调用”替代签名结果和 HTTP 状态的真实断言。

## Boundaries

- Always：签名先于语法检查和执行；外部响应有大小/超时上限；指标不包含用户名、密钥、路径或异常原文。
- Ask first：发布、推送、部署和生产探针。
- Never：创建或保存长期签名私钥；为拆文件改变数据库/认证/恢复语义；让公网请求触发 systemctl 或统计网络调用。

## Success Criteria

- 在线更新遇到缺失、错误、错误工作流身份或篡改 bundle 时不执行 bash。
- 正式 Release 包含 `install.sh.sigstore.json`；验证固定到本仓库、固定工作流、精确标签和 GitHub OIDC issuer。
- `hysteria2_panel.py` 不再内嵌 Web 资源、运维控制和更新实现，旧公开导入名继续可用。
- `/healthz` 对活着的 HTTP worker 返回 200；`/readyz` 仅在数据库、内部认证 worker、流量 worker和近期统计同步均正常时返回 200，否则返回 503。
- `/metrics` 仅回环地址可访问，外部地址表现为 404；输出不包含用户级数据。
- 安装器下载、校验、编译并安装新增模块；CI 覆盖模块和签名合同。

## Open Questions

- 无阻塞问题。首次从无签名旧版升级仍需在服务器 `/tmp` 使用临时工具和 bundle 验签；任务结束即清理，不在本地保存私钥、签名材料或长期文件。
