# v0.33.0 分机器自定义计费周期规格

## 目标

面板本机和每个远端数据节点都可以独立设置月流量预算、告警阈值、当前计费周期已经使用的流量，以及每月重置日。保存时以当下机器账本为基线，保存后的真实流量只追加一次；进入下一个计费周期后不再携带手工基线。

本版本同时允许管理员精确删除“升级前历史（未归属）”。删除范围只包含固定来源 `legacy-unattributed` 的分机器来源行、用户拆分行和日账本，不修改用户全局流量、任何已归属来源、节点、身份、spool 或配置。

## 不可破坏的边界

- 不修改用户 URI、域名、端口、token、证书 pin 或 Hysteria 长期身份。
- 不修改节点 Ed25519 身份、数据面配置或 durable traffic spool。
- 用户全局流量/设备限制与分机器供应商预算相互独立。
- 升级前已有预算自动保持“每月 1 日 UTC 重置、无手工基线”，结果与 v0.32.x 一致。
- 计费预算只告警，不自动摘流或停止节点。

## 计费模型

每个预算记录新增：

- `reset_day`：1–31，按 UTC 每月重置；当月没有该日时取当月最后一天，但下月仍按原始日计算。
- `manual_used_bytes`：管理员填写的本周期已用流量。
- `baseline_total_bytes`：保存瞬间该来源日账本的累计总量。
- `baseline_at`：基线保存时间。

当前周期由 `reset_day` 算出 `[period_start, period_end)`：

- 若 `baseline_at` 位于当前周期，显示用量为 `manual_used_bytes + max(0, 当前累计账本 - baseline_total_bytes)`。
- 若基线不在当前周期，显示用量只取当前周期日账本，手工已用量自然失效。
- 再次编辑已用流量会重新锚定当下累计账本，过去真实流量不会重复追加。
- 基线水位读取和保存使用同一个 `BEGIN IMMEDIATE` 写事务；与后台流量结算并发时，新增流量只会明确落在基线之前或之后，不会进入中间窗口。
- 重置用户流量不清除分机器日账本或预算基线。

## 管理接口与界面

- 现有 `POST /usage-origins/{origin_id}/budget` 保持路径不变，增加 `used_gib` 和 `reset_day`，两者均在服务端严格校验。
- `used_gib` 支持最多十二位小数，使用十进制定点换算，不使用浮点数；界面自动去掉无意义的尾零，范围为 0 到 SQLite 64 位整数上限。
- Dashboard 显示当前周期起止、下次重置日期，并让管理员直接编辑预算、已用量、告警和每月重置日。
- `POST /usage-origins/legacy-unattributed/delete` 仅接受登录管理员和有效 CSRF；页面要求明确确认，并记录审计事件。
- 已归属来源 ID 不允许进入历史清理接口，删除操作幂等。

## 安全与恢复

- 所有 SQL 使用固定语句和参数绑定。
- 数据库迁移为加列式，旧备份恢复后由初始化自动补列并采用兼容默认值。
- 备份保存预算基线、重置日和删除后的结果；恢复旧备份若重新出现未归属历史，管理员仍可使用同一精确清理动作。
- 一键安装/在线升级必须携带相同程序、数据库迁移、界面和文档，无额外手工补丁。

## 验收标准

- 本机与远端节点都通过：首次设基线、保存后追加、再次编辑不重计、跨周期归零、29/30/31 日及闰年边界。
- 缺失、负数、超大、小数精度过多、非法重置日、未知来源和缺失 CSRF 全部失败关闭。
- 未归属清理只删除 `legacy-unattributed` 三类统计行，用户总流量与已归属机器账本逐字节不变。
- 页面在 320/768/1024/1440 px 可用，表单标签、确认文案和状态可被键盘/辅助技术理解。
- 发布部署前后用户身份投影、Hysteria/节点私钥与配置哈希不变；真实数据面仍可连接。
