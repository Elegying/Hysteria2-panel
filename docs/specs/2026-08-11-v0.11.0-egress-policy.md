# v0.11.0 规格：设备限制语义与网页/视频出站策略

## 设备限制

1. 单用户默认限制为 3 个同时在线的 Hysteria 客户端实例。
2. 第 4 个实例认证返回 `ok: false`；前三个实例保持连接，不执行“踢掉最旧设备”。
3. 并发认证使用短期预留防止同一瞬间绕过限制；预留最多保留 5 秒。
4. 无法读取在线统计或持久流量时，新认证失败关闭。
5. 该计数不是物理设备指纹：一个网关客户端后面的多个终端仍可能只计为一个实例。

## 出站策略

1. 新安装以及没有旧策略字段的升级默认使用 `web`。
2. `web` 模式先拒绝本机、私网、链路本地、CGNAT 与 IPv6 ULA，再仅放行：
   - TCP 80、443；
   - UDP 443；
   - TCP/UDP 53；
   - UDP 123。
3. 其余目标和端口全部拒绝，从而阻断常规 BT/PT peer、DHT、uTP、邮件滥发、SSH 扫描和多数非网页滥用。
4. `full` 模式不写 ACL，保留 Hysteria 的完整代理能力；仅允许管理员通过安装环境变量显式选择。
5. 升级沿用已持久化策略；策略变化不得修改任何用户凭据、TLS 身份或分享链接。

## 安全边界

- ACL 基于目标地址、协议和端口，不是 DPI。使用允许端口的加密 P2P、外部中继或 VPN 套娃无法被可靠识别，因此文档不得宣称“绝对禁止所有 BT/PT”。
- `web` 模式会阻止游戏、邮件、SSH、非标准端口 API、部分语音和其他非网页业务；管理员应在兼容性与滥用风险之间明确选择。
- 面板、认证和统计监听不通过该 ACL 暴露；现有 systemd 身份与环回绑定继续作为控制面边界。
