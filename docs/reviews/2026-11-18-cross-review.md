# 两份 AI 审查报告复核

两份报告主要针对 v0.39.62。本次核对以本地快进后的正式标签 v0.39.63（3850b1b）为基线。下表中的修复均指本地源码。生产机器、第三方存储、客户端缓存和已发布的安装器需要分别验收。

## Word 报告的八项发现

| 编号 | 核对依据与结论 | 本次处理与边界 |
| --- | --- | --- |
| H2-01 | 成立。install.sh 的 uninstall_node 在签名 ACK 成功后先移除卸载 unit，再删除身份、状态和脚本。清理中断后，原入口会要求已删除的文件存在。v0.39.63 的流量排空修复没有消除此窗口。 | 将最后清理步骤持久化到独立可执行的 systemd unit，挂入开机目标，再移除身份和脚本。故障注入测试执行真实卸载函数，在 ACK 后让删除失败，再从落盘的 unit 完成清理。中央 ACK 表示业务已停并已结算，不能证明最后一个本机文件已经删除。 |
| H2-02 | 成立。远端认证及本地授权按 tier 比较就绪节点数和具有新鲜快照、流量确认的节点数。一个参与节点失联会影响同类节点的新认证，现有连接的状态需要另查。 | 节点页标明阻塞节点和受影响的普通或专线类别。保留全局设备数及配额检查；自动忽略失联节点会使仍在线的会话脱离计数。人工处置见运维手册。 |
| H2-03 | 成立。DataPlaneBootstrapService._identity 对普通节点调用面板身份提供器，对专线调用独立身份接口；普通节点获得同一私钥。节点控制请求使用另外的 Ed25519 密钥。 | 共享域名订阅固定单个证书指纹。更换数据面身份会影响缓存订阅及 DNS 多地址入口。项目方已确认保留一个逻辑节点，由 DNS 返回两个普通节点地址；两者须通过同一 pin 校验。按要求保留共享私钥，同一普通节点池内各服务器须处于同一信任域。DNS 和客户端缓存决定实际选址，不保证逐连接均分。 |
| H2-04 | 成立。便携 ZIP 含用户库、HMAC 密钥和本机 TLS 私钥。HTTPS、对象 ACL 和 OSS 服务端加密仍允许具备对象读取权限的一方读取内容。 | WebDAV 和 OSS 支持上传 age 密文。配置公钥时加密失败会终止任务。恢复密钥离线保存。旧配置仍上传 ZIP，网页手动下载仍是敏感 ZIP，已有远端对象也需要单独管理。 |
| H2-05 | 成立。原短命令通过 HTTPS 下载固定标签的 bootstrap.sh 后直接运行，脚本内部才开始验证安装器。长验签函数由测试和 E2E 使用。 | 保留短命令，在执行前验证独立嵌入的 SHA-256；README 两种快捷入口同步修复。测试校验工作树脚本与指纹一致，校验损坏下载会终止。取得可信命令本身仍是前提。 |
| H2-06 | 成立。原卸载逐项无条件写回首次部署前的 sysctl 值。 | 长期运行后的卸载逐项比对当前值与安装器设置，保留后来调整的值；配置文件内容已变更时保留文件。安装失败的事务回滚仍使用原快照。 |
| H2-07 | 成立。数据库、HTTP 和备份逻辑集中，存在维护成本。报告未证明文件长度直接造成某一功能错误。 | 消除 nodes 与 distributed 的反向导入，面板复用持久化目录同步函数。完整拆分数据库和 HTTP 层属于独立重构。 |
| H2-08 | 成立。便携备份主动排除旧命令、节点运行状态、会话及管理员。恢复要保留目标机身份配置并重新对接远端。 | 保持现有迁移格式和历史恢复语义。恢复范围由备份文档、管理界面和测试明确。整机灾备和三机故障恢复的 RPO、RTO 尚未实测。 |

## Markdown 报告的其他结论

| 发现 | 复核与处理 |
| --- | --- |
| output/ 可能入库 | 原忽略规则缺失，已加入根目录规则。本地索引和可达 Git 历史均无该目录记录；不能据此推断秘密已泄露。忽略规则不保护磁盘上的原文件。 |
| 版本链断点 | 原工作树落后一个正式提交，已快进到 v0.39.63。v0.39.61 有准备提交 3c73cef，远端无该发布标签。变更日志已注明，不补造标签。 |
| 订阅超额仍下发 | 查询已返回用量和额度，原处理器只检查启停、开始及到期时间。现在达到额度也返回 403，检查发生在恢复密码及组装外部节点之前。加入独立的每来源地址限流。原代理认证已检查额度。 |
| 订阅令牌和用量响应头 | 固定订阅地址支持缓存客户端、续费和迁移；拥有链接即可获取代理配置。文档已有重置机制。Subscription-Userinfo 面向持有链接的客户端。没有证据证明未持有链接的用户能读到他人用量。 |
| 移动刷新令牌 | 原轮换使旧令牌立即无效，但不能识别其再次使用。现在签发绑定会话的刷新令牌，重用已轮换的新版令牌会撤销该设备会话；其他设备不受影响。旧格式仍可正常轮换。新增独立刷新限流。 |
| 删除离线节点 | 删除对接会立即中央撤权，不会在失联机器上执行卸载。已新增已部署且仅中央撤权的待核实清单。在线断连、中央撤权和 DNS 运维具有不同语义；DNS 故障不应阻止紧急撤权。 |
| 告警和自动恢复 | 已有节点控制指标、运维告警条件及 systemd watchdog。未发现内置主动发送管理员通知的机制。节点页新增对认证有影响的状态提示。 |
| UDP 443、移动版文档 | README 多处仍描述按账号授权，移动当前能力仍标 0.5.6。已同步当前行为与 Android 0.5.7，并保留历史记录。 |
| 测试和日志 | CI 原无覆盖率统计，现由 Python 3.12 作业测量。原项目已有卸载、ACK 失败和网络快照测试，本次增加 ACK 后清理失败及网络参数漂移验证。服务由 systemd 运行，缺少应用文件日志轮转不能证明 journal 无轮转。 |
| HTTP、MFA、自签证书、卸载工具、OSS 安装方式 | 显式 HTTP 会暴露途经网络的管理流量；管理 HTTPS 有独立部署路径。当前无 MFA、无面板整机卸载入口，OSS 适配器独立部署。长期数据面证书以客户端 pin 校验。以上是部署风险或缺少的功能；报告未给出绕过登录、证书校验或既有面板卸载流程失败的证据。 |
| TCP 探测、平台与现场验收 | TCP 握手只证明端口可达；项目另外实现真实 Hysteria canary。Android 测试、公开 CI 配置和孤立函数测试均不能代替真机、真实 DNS/QUIC、重启断电和云端恢复验收。 |
