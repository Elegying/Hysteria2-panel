# v0.39.64 三份复审材料核对

核对基线为发布标签 v0.39.64（515a6b0）。转述稿复用了 Markdown 报告的发现，未重复计数。以下结论按运行行为核对，未采用报告的评分作为验收指标。

| 发现 | 结论与 v0.39.65 处理 |
| --- | --- |
| H2-R01 活跃节点卸载依赖发布站点 | 属实。节点部署时把排空模块按 SHA-256 持久保存；维护时先验证缓存，缺失或校验失败才下载并重新验摘要。只有部署过新版节点组件的服务器才有缓存。仍需能联系中央面板完成结算和签名回执。 |
| V-01 WebDAV 并发同尺寸改写 | 属实。时间戳粒度可能使元数据检查漏报。远端临时对象回读验证后、MOVE 前重新计算本机归档内容摘要。回归用例刻意保留原修改时间。 |
| H2-01 已 ACK 的节点在清理列表消失 | 属实。现依据持久部署时间等历史字段保留待核实提示。中央没有远端最终文件清理证明。清单说明 journal、服务和路径的核查方法。归档时清除未投递卸载命令，仅保留已投递命令用于签名回执重试。 |
| DNS 与紧急撤权 | 正常下线应先撤出该服务器的 DNS 并处理缓存。中央紧急撤权不依赖 DNS 或失联主机。单方面撤权无法执行远端卸载，清单不会建议运行缺少签名命令的卸载器。 |
| H2-02 同类节点快照过期阻塞认证 | 属实，是严格设备数及流量约束的可用性代价。保留失败关闭；已有阻塞提示和节点外 Prometheus 告警样例，实际通知取决于运维部署。 |
| H2-03 普通节点共享私钥 | 按用户要求维持一个订阅节点、同一个域名与指纹，域名可解析到两台普通服务器。单机失陷影响该信任域，逐次选择由客户端与 DNS 缓存决定。 |
| H2-04 异地备份未配公钥仍隐式明文 | 属实。WebDAV 和 OSS 均须通过公钥加密预检，或显式选择 allow_plaintext；选择明文会记录警告。升级前须调整旧配置。安装器在有相关配置时检查公钥，并为缺少 age 的主机尝试系统包安装。未配置异地任务的主机无需 age。 |
| 加密恢复与 age 门禁 | Web 恢复接收迁移 ZIP，离线解密说明此前已有。现把离线解密命令放到上传入口，澄清公钥、私钥与存储端各自位置。CI 的 Python 3.12 作业安装真实 age 工具，并测试生成迁移包、加密、模拟上传回读、离线解密和数据库恢复。手动下载仍返回敏感 ZIP。 |
| 限流误伤 NAT、429 缺少等待时间 | 属实。有效订阅和有效签名刷新令牌分别使用订阅 ID、会话 ID 分桶，无效请求按直连来源地址分桶，避免信任任意转发头。两处 429 都返回 Retry-After，测试覆盖同出口其他凭据。 |
| 固定订阅与流量显示 | 固定链接、可主动轮换、账号到期控制及持有链接的客户端读取字节用量均为已有合同。未发现未经授权读取其他账号用量的证据。未强加新的过期时间或舍入客户端用量。 |
| bootstrap 与标签 | “标签不存在”“摘要无测试”均不属实。GitHub 标签文件的 SHA-256 与 v0.39.64 源码一致，已有对接指令摘要测试；本次抽出命名常量。短命令先核对 bootstrap 摘要，bootstrap 随后执行 cosign 验签。长版本命令仍有测试和 E2E 调用方。 |
| 本地 output | 旧验收目录含运行态材料，已移入项目外当前用户专用目录；Git 索引及本地可达提交历史中均无 output 记录。没有发现据此需要重写 Git 历史的证据。 |
| H2-06 sysctl | 运行时调整与落盘配置有不同生命周期；卸载保留已变更的运行值和已编辑的文件。将临时 sysctl 修改自动持久化会改变管理员原意，未引入此行为。 |
| H2-07、H2-08 与其他建议 | 巨型模块是维护债；便携备份只恢复约定范围。MFA、面板整机卸载、整机 DR、额外覆盖率门槛和主动内置通知是独立能力。双 UDP 入口仍存在，旧账号字段用于兼容，Android 0.5.7 最初与面板 0.39.62 配套。没有以这些事实推断当前代理认证或数据恢复损坏。 |

本次没有在生产节点执行卸载、轮换证书、操作云存储或变更线上配置。模拟存储回读不能证明某个生产账户的恢复密钥仍可用。
