# v0.39.5 对抗性复查

本轮承接[部署与持久化审查](2026-09-05-deployment-reliability-audit.md)，以中断、并发、乱序响应和外部异常数据为切入点，新增确认四类缺陷；修复随面板 v0.39.5、Android v0.3.1+9 交付。

| 问题 | 旧实现的复现结果 | 修复和验证 |
|---|---|---|
| Android 会话归属竞态 | 退出后迟到的刷新成功会恢复旧会话；新账号登录后，旧刷新成功覆盖新账号，旧 401 清除新账号。 | 为会话操作绑定递增代次，拒绝跨会话响应与重试；凭据修改串行执行。测试覆盖退出、换账号、成功/失败乱序、安全存储延迟和迟到 401；失效会话的成功响应尝试撤销服务端新令牌。 |
| Android 显式端口绕过 | 地址含 `:0` 时仍返回可连接 URL，因为旧检查只检查独立端口字段。 | 对最终实际使用的端口检查 1–65535。回归覆盖 0、65536 和超长端口值。 |
| 上传归档发生变化 | 上传期间文件被写入后，旧实现在发布正式对象之后才报告变化。 | MOVE 前先比对归档文件签名；失败清理临时对象，不发布、不清理旧备份，继续保留发布后的复核。 |
| WebDAV 非法日期 | 符合文件名形状但日期为全零或 2 月 30 日的对象令清理抛出异常。 | 保留未知对象并继续处理合法的过期文件；临时上传与正式备份都做合法日期检查。 |

新增问题均先在旧逻辑上复现。运行时依赖继续使用标准库与已有 Flutter 包，没有新增生产依赖或变更数据库、备份格式及节点协议。

移动端此前只在 Android 发布工作流运行测试。本轮把固定 Flutter 3.47.2 提交的分析和测试加入 PR/main/tag CI，检查依赖锁文件未改变，并让签名发布再次要求 `mobile-tests` 成功。

验证组合包括三个 Python 版本的完整测试、SQLite 连接泄漏回归、Ruff/Bandit/ShellCheck、浏览器双视口、Flutter 静态分析与 16 项测试、源码哈希和秘密扫描。正式发布继续要求精确标签 CI、Ubuntu/Debian/Rocky 的双架构安装矩阵、APK 原签名与 arm64 ABI、Sigstore/SBOM 以及匿名下载验签。

本地候选验证结果：Python 3.8.20、3.12.14、3.13.15 各 706 项全部通过；Flutter 3.47.2 分析无问题，16 项测试全部通过。浏览器 1380×900 / 375×812 冒烟、19 个安装器源码哈希、静态检查、文档链接和秘密扫描均通过。

生产更新采用原有固定版本事务与逐台更新方式：更新前后比较用户和流量、数据库完整性、TLS/节点身份、服务、端口和维护标记，再验证真实 UDP 入口。未配置的 WebDAV 不凭空填写外部目标。测试环境结果和当前启用功能的线上结果分别记录，不能把截图、单元测试或历史发布记录作为未执行功能的验收证据。
