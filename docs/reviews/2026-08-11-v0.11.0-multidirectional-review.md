# v0.11.0 多方向项目审查

## 结论

本轮从滥用、认证、安全、性能、迁移、运维和供应链七个方向复审。已修复两个确认问题：节点没有出站防滥用策略，以及界面把官方“客户端实例数”错误描述为“并发连接数”。在 94 项测试、静态检查和 Hysteria 2.12.1 真实配置启动验证通过后，没有剩余发布阻断项。

## 已修复

### 高：认证用户可使用任意出站端口和访问私网

旧配置没有 ACL，认证用户可以发起 BT/PT、DHT、SMTP、扫描和私网访问。v0.11.0 默认 `web`，先拒绝私网类地址，再只放行网页/视频端口并拒绝其余流量；策略持久化且支持显式 `full` 兼容模式。

### 中：设备计数文案与官方语义不一致

旧界面和文档把 `/online` 数量称为“并发连接”。官方定义是同一认证 ID 的 Hysteria 客户端实例数，不是代理流数量。代码行为没有错，但说明会误导管理员。界面、README、API、ADR 和回归测试现已统一。

## 已验证边界

- 第 4 个客户端实例被拒绝，前三个保持在线，不调用 `/kick`。
- 并发认证预留防止瞬时竞态；统计接口失败时认证失败关闭。
- 出站规则由上到下首条匹配，私网拒绝位于端口放行之前。
- `web/full` 值被严格校验，重复安装沿用持久化值。
- ACL 变化不接触用户 token、HMAC、数据库、TLS 证书、私钥或证书指纹。
- 备份恢复仍只迁移用户和节点身份，不覆盖目标服务器的出站策略。
- 官方 Hysteria 2.12.1 Darwin arm64 二进制经 GitHub Release SHA-256 校验后，能使用完整 ACL 配置真实启动。

## 保留风险

### BT/PT 识别不是绝对保证

Hysteria ACL 不做 DPI。伪装在 TCP/UDP 443、TCP 80 或外部中继中的加密 P2P 仍可能绕过。继续叠加常见 BT 端口黑名单没有实质收益；更可靠的后续手段是异常流量、目标扇出和云厂商滥用告警。

### 设备数不是硬件授权

一个热点/网关客户端后面的多台终端可能只计一个实例；同一设备运行多个核心也可能计多个实例。没有稳定、兼顾隐私且无法伪造的硬件标识可由 Hysteria 服务端获得。

### HTTP 管理面仍是最高运营风险

HTTP 会明文传输管理员密码、会话 Cookie 和完整迁移 ZIP。现有 CSRF、CSP、会话控制和 5 次错误锁定不能提供传输加密。按当前产品取舍继续默认 HTTP，但生产必须把面板端口限制到可信管理来源，避免对全网开放。

### 大用户量页面线性增长

按现有产品要求，面板一次渲染全部用户并在浏览器内搜索。356 用户仍属于可用规模，但每个用户包含 5 组操作表单，响应体和 DOM 会随用户数线性增长。达到约 1000 个用户前应改为服务端搜索或分批/虚拟渲染，同时保持“无传统分页”的交互。

### 拒绝原因与滥用缺少面板可观测性

Hysteria HTTP auth 对客户端只能返回统一拒绝，当前服务日志也没有按“设备上限、流量上限、统计故障”聚合计数；ACL 拒绝同样没有面板趋势。故障排查和滥用处置仍主要依赖 journal 与云厂商通知。

### 运行系统生命周期

当前生产服务器是 Ubuntu 20.04；根据 [Ubuntu 官方发布周期](https://ubuntu.com/about/release-cycle)，其标准安全维护已于 2025 年 5 月结束，只有启用 Ubuntu Pro/ESM 才继续获得扩展安全维护。面板支持迁移身份，下一台服务器应优先使用 Ubuntu 24.04 LTS，并完成一次旧链接连续性恢复演练。

## 后续路线图

1. **先做生产迁移演练**：新建 Ubuntu 24.04 LTS 服务器，部署、恢复最新 ZIP、切换 DNS，验证旧 URI、YouTube、网页、流量和 TCP 探测后再退役 20.04。
2. **增加策略可观测性**：面板展示设备上限拒绝、流量上限拒绝、统计故障和 ACL/服务异常计数，并提供近 24 小时高风险用户排行。
3. **增加真实安装矩阵**：CI 在隔离的 Ubuntu/Debian/Rocky 环境执行完整安装、升级、回滚与 systemd 就绪检查，不再只验证 Shell 文本契约。
4. **优化大用户量 DOM**：保持无传统分页，但采用服务端搜索或分批渲染，建立 356/1000/5000 用户响应大小与耗时基线。
5. **强化 HTTP 管理边界**：提供可选的面板监听地址和管理 IP allowlist 生成提示；不强迫改用自签名 HTTPS。
6. **增加周期恢复测试**：每次发布用脱敏测试备份自动演练恢复与回滚，生产每月人工验证一次可下载、可校验、可恢复。
