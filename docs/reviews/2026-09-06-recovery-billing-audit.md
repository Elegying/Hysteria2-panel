# 新服务器部署、恢复及节点计费审查

## 本次故障及修复

| 问题 | 根因与处理 | 回归证据 |
|---|---|---|
| 旧备份恢复后面板无法启动 | v0.39.7 数据已写入，但恢复收尾读取旧结构；应用与收尾统一迁移视图（v0.39.10） | `BackupManagerTests`、`OperationsTests`、六平台真实 systemd 恢复 |
| 恢复事务跨时间重入不一致 | 新本机来源创建时间依赖当前时钟；改用稳定时间并兼容旧事务 | 跨时间重入、精确账本与篡改拒绝测试 |
| 一键对接停在 timer 创建后 | 恢复改变 env，出口策略摘要仍是旧值，安全检查拒绝 bootstrap；恢复完成前重新验证并同步摘要（v0.39.10） | 恢复出口策略回归、真实节点控制与直连验收 |
| 启动期间过早判恢复失败 | 采集器启动重试可能超过短等待；扩展有界就绪窗口 | 暂态未就绪、最终失败及保留事务测试 |
| 重装服务器 SSH 无法连接 | SSH 主机身份改变或旧私钥失效；按用户确认建立独立主机密钥记录，使用已授权登录方式 | 新身份验证；不关闭 SSH 主机校验 |
| 便携备份混入旧机器来源及预算 | 旧格式迁移范围过宽；v0.39.11 只导出用户及连接身份，恢复保留目标机器账本 | 10 万条运行时记录压实、旧包兼容、目标账本保持 |
| 恢复后可能混用已接入节点身份 | 恢复前检查证书、HMAC、同名账号与已删除用户名隔离；正常恢复撤销会话、排固定清连接命令 | 冲突停机前拒绝、目标节点保持、旧账号隔离 |
| 已有节点恢复触发数据库行类型错误 | 新复用的固定命令函数需要 Row 类型；在恢复临时数据库显式设置 | 已接入节点恢复测试 |
| 恢复 HTTPS 检查关闭证书验证 | 固定回环连接，使用系统 CA 和受信本机证书，校验真实域名；拒绝重定向 | 真实 TLS 正例、错误域名、重定向拒绝，生产证书只读检查 |
| 节点统计/预算未按双向计费 | 机器展示和预算统一为 `2 × (tx + rx)`，用户与入库原始账本不变 | 本机、远端重放幂等、月份边界、人工基线、管理 API |
| 用户重置或恢复影响机器累计展示 | 展示改读独立每日机器账本，与机器预算同源 | 用户重置后机器累计与预算保持 |

## 计费及恢复流程复审

- 原始流量只在成功结算批次中入库一次；两倍换算仅发生在机器展示和预算读取，升级不乘写历史数据。
- 人工“当前已用”是服务商计费值；其后仅新增实际流量乘二，进入新周期按新周期累计。
- 用户额度、本人查询、域名业务流量保持实际 `tx + rx`。机器预算告警不自动停机。
- 用户备份恢复采用目标数据库快照，保留服务器身份、节点控制凭据、机器每日账本及预算；只替换用户、清理其短期状态。
- 旧机器来源不导入，用户累计转为未归属历史。保留并补充已删除用户名隔离记录，不允许旧身份重新分配。
- 恢复预检在停机前执行，root 写入前再次验证。新事务记录用户恢复范围，收尾从受保护目标快照重建预期数据；旧事务继续按旧合同校验。
- ZIP 白名单、大小/解压限制、SHA-256、证书/私钥、用户 HMAC、数据库和外键验证、权限及持久事务回滚均保留。
- 安装及节点接入保留签名来源、身份绑定、固定命令、时限与失败关闭；不会删除事务标记伪造成功。

| 域名流量、分页、筛选、排序 | 数据库/HTTP/浏览器与管理 App 合同 | 只读域名统计接口 |

涉及删除账号、断连、关机、完整恢复等破坏性路径在隔离环境验证；没有为测试而在生产执行。生产只读检查不等同于对所有危险按钮做了真实操作。

## 部署边界

支持范围以 Ubuntu 24.04、Debian stable、Rocky 9 的 amd64/arm64 六个平台安装验收为准。DNS、云安全组、ACME/GitHub 网络和特定主机自定义配置由预检及现场证据确认，不能承诺任意新服务器无条件完美部署。

源码审查和验证不能保证客户端永远无法破解。安全边界仍在服务端：每个账号仅查询本人，管理接口需要独立管理会话，客户端不持有服务器管理密钥，错误或过期状态不返回个人统计。
