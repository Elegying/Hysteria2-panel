# 线路检测与网卡实时速度

节点统计卡片的重置日后可打开“线路检测”。TCP 全部可达时显示绿色“TCP 可达”，探针报告部分或全部 TCP 无响应时显示红色“TCP阻断”；该文案只表示 TCP 探测失败，不是已证实被墙。未检测、过期、探针或接口故障显示灰色提示。认证、出网和 DNS 的独立证据仍在详情展示。该功能只检测，不改变 DNS、节点权重、用户凭据或订阅地址。

## 证据与结论

- **国内 TCP**：调用 [Globalping 官方公共 API](https://github.com/jsdelivr/globalping/blob/master/public/v1/spec.yaml)，严格选择 `country=CN` 的电信、联通、移动 ASN，分别探测 TCP 443 与配置主端口，每个探针 3 个包。结果显示运营商、城市、丢包、延迟、检测时间与原始结果链接。缺少运营商探针时显示未取得有效结果，不用境外探针代替。
- **代理出网**：面板运行 Hysteria2 客户端，连接指定公网 IP，使用既有域名 SNI 与证书指纹，通过 SOCKS5h 访问固定 Cloudflare HTTPS trace 域名并核对出口 IP。抽测 UDP 443、配置主端口；远端节点额外抽测一个随机跳跃端口。本机发包不经过 PREROUTING 入站转发规则，本机跳跃端口明确显示需外部验证，不用自检结果判断入站转发是否正常。面板自身节点是本机自检，其余节点是从面板发起的跨节点检测；都不代表国内路径。
- **国内 UDP**：公开免费 API 不支持运行带认证的 Hysteria2 客户端，因此始终明确标记“未验证”。普通 UDP traceroute、TCP、Ping 或境外成功都不能证明国内 QUIC 可用，也不能确认所有地区、运营商和用户能正常使用。
- **疑似国内路径受阻**：同一节点连续两轮（20 分钟内）出现同一运营商/端口的无响应，且面板侧两个 TCP 基准及各代理出网测试均成功，才显示疑似提示。仍需国内真实客户端复现，不能断言被墙；TCP 监听故障、探针故障、DNS 不含节点、认证或出网失败分别展示。
- 检测仅由管理员点击“立即检测”发起；启动、打开页面及后台采样均不会自动发起网络探测。每节点手动冷却 60 秒，全局仅一个任务。结果超过 20 分钟标记过期；进程重启后重新检测，不显示旧结果为当前状态。

## 免费源与边界

Globalping 是 jsDelivr 的公开分布式探测项目，匿名额度为每小时 250 个探针测试，无须注册或 API 密钥。面板内置更低的每小时 180 次上限（四节点、双端口、三个运营商手动完整检测一次约 24 次），尊重 429 并退避一小时，使用 gzip、ETag 与低频轮询。免费公共探针没有可用性或运营商覆盖保证；额度不足、超时或缺少探针时显示检测不完整。

第三方只收到公网 IP 与 TCP 端口，不接收用户凭据。其测量结果是公共数据。真实代理使用内存中的随机短期内部凭据，按本机/节点隔离，90 秒后不能再认证；每个测试结束立即撤销，客户端进程退出。内部身份不创建用户、不占用户设备名额、不进入订阅；诊断的少量实际流量仍可计入机器总流量。

管理接口需要既有管理员会话；发起检测还须通过 CSRF。检测目标只来自当前启用节点，拒绝任意目标/IP 输入。TLS 验证、节点签名、防重放、生命周期检查与日常用户授权路径保留。

## 网速口径

折线图读取 Linux 默认路由网卡的 RX/TX 累计字节，按同一启动周期的单调时间差计算 bytes/s，界面换算为 Kbps/Mbps。**入站/出站是服务器网卡方向**，包含代理和系统流量，不等于用户上传/下载或服务商月度计费值，不用于扣除用户配额。

面板每 5 秒采样，远端沿现有签名控制周期上报（约 2–5 秒），界面每 5 秒读取缓存；展示最近 5 分钟。内存每节点最多 180 点，总节点上限 512。旧 Agent 无此样本时显示数据缺失，不用历史账单伪造速度。首个样本、计数回退、重启/换网卡、超过 20 秒断档均不连线；过期时当前值显示“—”，已知空闲才显示零。

新 Agent 只在已验证 HTTPS 响应包含遥测能力标记后发送可选签名字段。旧 Agent 能继续使用新版面板；新版 Agent 连接旧面板时不发送新字段。整个变更没有数据库结构迁移。原有安装器固定源码 SHA-256、签名验证、流量结算及回滚边界保持不变。

## 验证

- 单元测试覆盖目标隔离、撤销和超时、维护期间认证关闭、签名遥测与重放拒绝、非大陆探针拒用、第三方目标不匹配、额度限制、速度断档/重启/零值。
- 管理 HTTP 测试覆盖登录、CSRF、固定节点目标与缓存不可公开。
- 浏览器验证折线绘制、速率单位、检测结果范围、详情弹窗与窄屏不溢出。
- 发布须通过仓库完整 CI 与六平台安装器矩阵，再生成签名发布；升级顺序为面板先、节点后，每台升级前后核对用户/订阅、证书与节点身份。
