## 修正迭代

1. 首轮不通过：旧 CSS 的最小高度导致卡片偏高；用户表单未完全与总览分离；提交后视图返回不一致。修正高度、独立视图、原生表单返回位置；关闭凭据弹窗仍真正刷新用户数据。
2. 第二轮不通过：实时速率只有线条，缺少模板中的面积、完整刻度与右侧速率栏。改为青色/紫色面积折线图，增加速率纵轴、分钟横轴、图例与顶栏数值；节点图左置，速率右侧纵向排列。缺失数据保持断档，不填成零。
3. 逐模块审查：修复新外部订阅入口只开弹窗、不加载数据的问题；移除重复页面标题；订阅分成普通、自建专线、外部线路、用户订阅四个入口；系统资源明确为刷新时的快照，本机控制明确列出本机 IP。

## 本地验收修订：服务器运维（未发布、未部署）

- 导航合并为五个模块，节点页采用紧凑三列服务器卡片；备份恢复仅从设置页进入，设置页增加检查更新。
- 编辑用户与订阅弹窗缩短说明、统一字段高度、顶部对齐；保留日期边界、订阅刷新和端口监听等必要提示。
- Agent 通过协商后的签名控制周期上报 CPU、内存、根分区磁盘与运行时长。面板每 5 秒读缓存，30 秒后标记过期；未升级 Agent 不会伪造资源或允许执行操作。
- 远端重启服务和服务器使用固定命令、管理员会话及 CSRF 校验、目标确认、两分钟有效期、并发与冷却限制。执行前暂停目标节点的新认证并结算流量，持久化执行意图防止重放；失败或超时解除认证限制，其他节点不受该限制影响。
- “节点已确认重启安排”仅表示 systemd 已接受调度，不宣称操作系统已经重启成功。尚未在真实服务器运行这些操作。
- 验证：面板/检测/网页失败路径 121 项、分布式协议/Agent/运维 101 项、浏览器 36 组通过。签名测试使用临时编译的 OpenSSL 3.5.4；Ruff、JavaScript/Python 与 Shell 语法检查通过。
- 本地预览使用隔离数据库、模拟资源和模拟操作回执；真实资源采集、固定 systemd 参数、过期与重放保护另有自动测试。线上版本和服务器未改动。
