# ADR-010：默认 web 策略允许公网 SSH

## 状态

已接受

## 日期

2026-08-12

## 背景

默认 `web` 出站策略为了阻断常规 BT/PT、扫描和非网页流量，过去只允许网页、DNS、NTP 和管理面板端口。管理员连接 Hysteria 节点后，SSH 到公网服务器的 TCP `22` 会被 ACL 主动关闭，表现为 TCP 建连成功但在 SSH 密钥交换前收到 `Connection closed by remote host`。

仅放行当前两台服务器可以降低滥用面，但不能满足管理员通过节点管理任意新增公网服务器的要求。客户端直连规则也只修复单台设备，无法覆盖所有管理终端。

## 决策

默认 `web` ACL 在所有环回、私网、链路本地、CGNAT 和 IPv6 ULA 拒绝规则之后，增加 `direct(all, tcp/22)`，允许任意公网目标的标准 SSH 端口。规则仍位于最终 `reject(all)` 之前。

## 后果

- 管理员连接节点后可以 SSH 到任意公网服务器，不需要维护 IP 白名单。
- 服务器本机、私网、链路本地和 CGNAT 的 TCP `22` 仍被前置规则拒绝。
- 已发放节点链接和节点身份材料不发生变化。
- 代理账号也可能被用于公网 SSH 扫描或口令爆破；用户限额、流量统计、审计与快速禁用仍是必要控制。
- 非标准 SSH 端口继续被 `web` 策略拒绝；需要任意端口时必须明确选择 `EGRESS_POLICY=full`。
