# ADR-020：以原节点凭据只读查询本人用量

- 日期：2026-09-06
- 状态：已实现

## 背景

旧节点 URI 只承载数据面地址和认证/证书参数。SSRVPN 需要展示账号总流量与在线实例数，既不能向普通用户开放管理员或机器接口，也不能在用户查询时触发流量清零、额度校验或设备租约。

## 决定

新增独立 HTTPS `GET /api/v1/user/usage`，使用既有 HMAC `token_fingerprint` 查找账号，将身份识别与代理连接许可分开。停用/超额账号保留本人查询权，删除/轮换立即对后续只读事务生效，不缓存身份授权。

复用账号总账与原有后台采集/签名节点上报，不新增客户端计费来源。查询没有网络采集、结算或控制副作用。本机后台成功轮次发布短期内存检查点；远端增加最小运行态检查点，记录成功结算批次的原始采集时间及后续在线快照序号。使用最旧来源固定 30 秒有效期，缺失或不完整失败关闭。新表不进入可移植备份，服务新 epoch 清空。

限制在现有 HTTPS 监听器中独立划分并发名额、限流和请求期限；查询使用有界只读 SQLite 事务，不抢占采集互斥锁。运行时不接受任意外部 URL。

中央服务地址与自有节点的绑定由 SSRVPN 的受信任配置注入，与旧节点 URI 分离。无绑定时不发送密码，禁止名称推断、扫描和 TLS 降级。

## 代价与回退

允许展示有效期内的最近一次完整快照，不能即时检测无显式上报的断网；来源时钟领先、活动节点 standby 或采集故障时，保守返回 503。接口与管理面板共用监听器，握手与请求行之前的连接仍受原全局服务器资源边界约束。

旧客户端和旧账号无需迁移。旧服务版本忽略新增运行态表；回滚只按原更新器文件/事务回滚，不重置业务数据。完整 HTTP、客户端配置和验证契约见 [CLIENT_USAGE_API_V1.md](../CLIENT_USAGE_API_V1.md)。
