# ADR-014：有界组合节点控制周期

- 状态：已接受
- 日期：2026-08-30

## 背景

旧数据节点每个短周期分别上传流量、在线快照和轮询命令。任一流量上传失败会提前结束整个周期，既阻止后续本地流量采集，也延迟停用、摘流等控制命令；大量节点按固定间隔恢复时还会形成同步重试。

## 决策

新增签名域 `control-cycle` 和 `/api/v1/node-control-cycles`：一次请求最多携带 8 个已持久化流量批次、一个可选在线快照和一个命令轮询。服务端先完整验证有界结构、节点签名、绑定 IP、时钟和限速，再复用既有幂等流量账本、单调快照与固定命令队列。流量与快照 ACK 仍按对象返回，节点只有收到中央提交 ACK 才删除 spool。

节点先采集并 `fsync`，再尝试上传；容量允许时，旧批次上传失败不阻止新批次落盘。控制请求失败后仍单独轮询命令，随后保留原错误进入有界退避。循环等待加入 ±20% 抖动，请求超时从 10 秒缩短为 8 秒，快照安全窗口相应为 43 秒。

## 兼容性与安全边界

原有五个节点接口全部保留。新版 Agent 只在组合接口返回 404 时记忆降级到旧协议；403、签名失败或畸形响应绝不降级绕过。旧 Agent 可直接连接新版面板，因此面板和数据节点无需同时升级。协议不传输或修改用户 token、URI、HMAC、节点 Ed25519 私钥、Hysteria TLS 身份或统计 secret。

## 后果

正常周期由三次签名/HTTPS 往返减少为一次，中央验签与限速开销下降；命令在计量链路故障时仍可送达。单次请求可能在响应丢失前已部分提交，因此重试使用新外层 nonce，并依靠既有 `(nodeId,batchId)` 幂等账本和单调快照序列安全收敛。
