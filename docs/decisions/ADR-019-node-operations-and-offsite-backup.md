# ADR-019：节点运营生命周期与异地备份

- 状态：已接受
- 日期：2026-08-29

## 背景

现有系统已经能把面板本机和远端节点的累计设备/流量分开归属，但管理员还不能设置
机器预算，也缺少不会误伤用户的标准停机路径。可下载备份能够完整迁移身份，但没有每日
异地副本。

## 决定

1. 月度预算使用独立的 UTC 日增量账本，而不是从累计计数猜测月初基线。
2. 预算告警不直接停机；停机必须进入显式生命周期和 DNS/在线/流量结算门禁。
3. 远端节点只接受 `STOP_DATA_PLANE` 和 `START_DATA_PLANE` 两种新增固定命令；Agent
   永远不执行服务器提供的 shell、unit 名或路径。
4. DNS 继续由管理员修改。面板只解析和验证，不持有 DNS 厂商凭据。
5. 异地备份采用 root-only 配置的 HTTPS WebDAV。安装器交付能力与定时器，目标未配置
   时明确报告未启用。
6. 停止数据面不停止 Agent、不删除节点身份、不清理 spool；因此可以可靠 ACK、恢复或
   安全重绑定。

## 后果

- 增加少量 SQLite 日账本，但查询范围只覆盖当前自然月，可建立来源/日期主键。
- 安全摘流至少需要一次人工 DNS 修改，这是保持 DNS 凭据和用户配置边界的必要步骤。
- 没有 WebDAV 地址和凭据时不能宣称异地备份已经生效；定时器只记录“未配置”，避免
  在面板服务器上无边界堆积重复备份。
- 外部消息推送不属于本次范围；后续可在不改变预算模型的情况下增加固定 webhook 通道。
