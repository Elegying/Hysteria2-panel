# ADR 028：运行时出口能力与静默降级

状态：已实现；真实客户端验收通过，正式部署遵循现有发布门禁。

安装时的 IPv6 路由查询不再作为永久的地址族结论。受管数据面基于固定
Hysteria 2.12.1 提交构建，在实际出口执行有界的 HTTPS DNS 和 UDP DNS 请求。
两家 IPv6 服务均不能证明可用、且 IPv4 对照成功时，后续连接使用 IPv4。
两族均失败表示未知，不改变节点认证、订阅可用性或普通用户界面。

每五分钟对活跃出口复测，恢复需要三次连续成功和十分钟冷却。
模式由每次新建连接取得，已有 TCP 及 UDP 对象不因模式变化被关闭；
切换模式不重启服务。服务进程使用独立的 systemd StateDirectory，目录 0700、
诊断文件 0600，保存时间与结论而不保存用户目标、账号或订阅令牌。

系统解析在降级时仅查询 A，并使用 IPv4 DNS 传输。系统 DNS 超时可回退到
固定公共 IPv4 DNS；不重新解释 NXDOMAIN，不向公共 DNS 回退单标签或 .local 名称。
解析仍位于 ACL 之前，原私网拒绝与认证、额度限制不变。纯 IPv6 字面地址或
没有 A 记录的目标不能凭空翻译为 IPv4。第三方客户端只需继续使用原订阅。

环境开关仅用于面板生成的默认 direct 出口模板。检测到显式地址族限制或
绑定接口/地址的 direct 配置时，进程停用自动判断，避免把默认路由的检测结果
用于另一个出口。自定义多代理出口不在此模板支持范围。

`native/adaptive_egress/build.py` 校验固定提交和 Go 1.26.5，先运行 race 与
上游 outbound 回归，再生成 Linux amd64/arm64 构件及来源记录。安装器按实际
SHA-256 校验受管构件，不能用未带扩展的官方二进制替换。核心镜像是独立构件，
其固定版本只增不改；面板正式版本仍遵守现有完整发布门禁。

首次升级仍遵守现有维护锁、认证暂停、在线会话排空、流量结算、备份与回滚协议。
用户身份、证书、节点签名身份、统计 spool、跳跃端口和订阅 URL 不迁移。
回滚恢复旧二进制、服务单元与配置；诊断文件不作为认证或计量依据。
