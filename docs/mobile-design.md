# 移动管理客户端设计说明

Android v0.4.0 使用 Flutter 实现，借鉴 Apple 的界面层级与交互原则。它没有调用仅适用于 Apple 平台的 Liquid Glass API，也不宣称复制其光学折射实现。

## 文档研究与实现

- [Materials](https://developer.apple.com/design/human-interface-guidelines/materials)：区分导航与内容层。导航、弹窗保留裁剪模糊与高光边缘，数据卡片默认实色；高对比度模式关闭模糊。
- [Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/)：避免玻璃层反复叠加。首页通过深色主卡突出服务状态，用真实在线节点比例构建进度环；没有添加虚构流量曲线。
- [新设计系统](https://developer.apple.com/videos/play/wwdc2025/356/)：根据功能组织操作，统一圆角与留白。先读状态和预算，再进行服务维护；四个主导航始终保持相同位置。
- [Motion](https://developer.apple.com/design/human-interface-guidelines/motion)：导航指示在 320 毫秒内移动，连续点击可立即改变目标；开启减少动画时直接切换，业务操作不等待动画完成。
- [Typography](https://developer.apple.com/design/human-interface-guidelines/typography) 与 [Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)：使用平台字体、明确的文字层级，允许系统字号缩放；状态同时用文字和颜色表达。两倍字号时主卡优先留出文字空间，节点数量仍可在统计卡读取。

## 使用

首页查看服务状态、在线节点与流量预算，下拉可刷新。用户页管理账号，节点页点击卡片查看详情，设置页选择深浅外观与主题色。重启、停止和删除等操作继续保留原有确认流程。

80% 和 95% 的预算颜色仅为数据提示；节点是否停用仍由服务端策略决定。面板自身节点与没有配置预算的对接节点均保持原有规则。

## 验证范围

组件回归覆盖窄屏、两倍字号、深浅主题、高对比度、导航切换、刷新竞态与表单取消。使用脱敏测试数据进行截图和真机界面验收；这类截图只证明界面渲染和交互，不代表生产账号或网络链路实测。

## v0.4.1 Premium 全界面预览

复用 SSRVPN 本地修补版 [Liquid Glass Widgets 1.4.4](https://pub.dev/packages/liquid_glass_widgets)，代码位于 `mobile/third_party/liquid_glass_widgets`，保留 MIT 许可及补丁来源说明。按用户验收反馈，公共卡片、按钮、输入框、筛选菜单、开关、二级详情与弹窗均接入 Premium 材质，关闭自适应画质。卡片外层使用 Premium 折射；在支持共享捕获的设备上，内外卡片及按钮均使用独立的共享纹理取样层，避免嵌套控件退回实时背景滤镜。原生输入控件保留焦点、校验、禁用状态和无障碍语义；危险操作仍经过确认。

| 界面 | 覆盖内容 |
| --- | --- |
| 登录 | 登录卡片、地址/端口/账号/密码输入、密码显隐、登录按钮 |
| 首页 | 状态主卡、统计、预算、服务控制、资源小卡、一键对接表单及结果、维护确认 |
| 用户 | 流量排行、搜索、状态/排序玻璃选择菜单、用户列表、新增表单、开关 |
| 用户详情 | 数据小卡、操作标签、编辑、额度、启停/改密/删除确认、分享与二维码弹窗 |
| 节点 | 汇总、节点列表、实时流量、详情、紧急控制/断连确认、复制入口 |
| 流量详情 | 全局/单用户详情、返回、刷新、列表、失败重试 |
| 设置 | 版本、会话、更新提示、主题选项、强调色、退出确认 |

系统输入法、系统分享面板由 Android 提供，App 不替换其外观；二维码像素保留清晰实色底以确保扫码。高对比度与减少动画遵循系统设置。

### 背景

内置工具 imagegen 生成 `mobile/assets/liquid-tech-background.png`（1024×1536）。生成提示：深海蓝与近黑的科技背景，稀疏青蓝光点、柔和散景斑点与薄雾，低亮度，无文字、标志或 UI，边缘可供轻微平移。图片在全局背景层 按 SSRVPN 的 18 秒余弦周期缓慢移动，内容本身保持静止。切后台、TickerMode 关闭或系统减少动画时暂停；图片不逐帧重解码。

### 验证与构建

最高画质需要支持 Impeller 的设备；组件测试不代表真机着色器效果或持续帧率。必须验收快速切页、列表滚动边缘、二级菜单、弹窗与键盘、深浅外观。

预览应用名“H2 液态玻璃预览”，独立 `.preview` 应用标识，与正式版共存；同签名覆盖安装保留预览版登录。不内置账号或密码。

```sh
GRADLE_OPTS="-Dorg.gradle.project.previewBuild=true" flutter build apk --release --target-platform android-arm64 --build-name 0.4.1-preview.4 --build-number 21
```

签名配置只从本地受保护文件读取。预览不改变服务端流量预算和停用规则。


### preview.4 卡顿与交互修复

滚动卡片使用独立 Premium 材质，避免跨页共享绘制数据。Android Impeller 使用库的完整分辨率背景纹理取样路径，保持三维折射、色散与高光；隐藏标签的动画和定时刷新暂停，当前标签保持实时更新。没有降低玻璃质量或关闭背景运动。

修正浮动输入标签裁切、筛选标题裁切、操作按钮双边框，以及新增用户按钮的形状和大字号空间。回归覆盖长列表滚动、输入标签裁切边界、背景取样调度、图层复用及原有窄屏/两倍字号等场景。真机帧间隔使用 SurfaceFlinger 的 Flutter Surface 呈现记录；Android 外壳的 gfxinfo 数字不用于宣称 Flutter 流畅度。

登录页自动填充上次成功登录的面板地址、端口和账号；退出登录仍保留这些连接信息，但会删除安全存储中的刷新令牌。密码不写入普通配置，读取较慢时不会覆盖已经开始输入的内容。顶部操作按钮统一保留 16 dp 右侧间距。

### SSRVPN 渲染优化移植

背景绘制版本改变时，全界面共享一张完整分辨率纹理；静止时不循环抓图。使用修补后的局部逻辑坐标采样，首帧纹理未准备好时不读取实时背景；旧纹理延迟回收。每个表面使用独立 BlendGroup，避免管理端全局容器累计超过着色器支持的 16 个形状。着色器及静态图层复用，减少重复创建。保留 Premium 折射、色散与边缘高光，不通过降低质量修复黑块。

源快照包含 SSRVPN 尚未提交的本地优化，来源说明见 `mobile/third_party/liquid_glass_widgets/H2_INTEGRATION.md`；本次未修改 SSRVPN 项目。编译与组件测试不代替快速滚动的实机验收。

### preview.5 系统资源与持续绘制修复

修正嵌套 GlassSurface 被排除在共享取样之外的问题。1.4.4 修补版与 1.5.0 的嵌套行为不同，不能假设 avoidsRefraction 一定触发 vibrancy。资源小卡与按钮现在同样使用独立形状组及共享纹理。

背景捕获边界移到平移变换内部；使用真实放大的布局尺寸避免坐标单位不一致。背景像素不变时仅更新 origin，图片晚到、尺寸及 DPR 变化仍使纹理失效。新增测试持续推进背景运动并断言 image 身份不变、origin 改变及卸载释放；保留 Premium、分辨率和运动效果。系统资源的重启服务器按钮去除原生灰色填充，使用橙色图标，确认流程保持原有逻辑。

2026-09-15：静态分析通过，69 项测试通过，preview.5 (22) 覆盖安装。系统资源 5 轮往返滚动录屏抽查及运动原尺寸帧未见此前分层错位。重启确认框因设备切回桌面未完成实机验证；没有执行服务器重启。电池温度先后读取 41.9°C / 40.1°C，均报告正在充电，不能作为受控降温或长期热稳定性证明。
