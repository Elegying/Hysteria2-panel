## 逐页与交互复核

以已选定的五张手机渲染图为参考，重新捕获实际 Flutter 页面；参数为 1200×2608、设备像素比 3，模拟顶部 28 / 底部 24 逻辑像素安全区，键盘占用 320 逻辑像素，字体比例 1.0 与 1.3。密度、安全区和键盘高度为测试设定，不冒充真机实测值。屏幕规格参考：https://www.gsmarena.com/xiaomi_17_pro_max-review-2895p3.php 。

测试：163 项 Flutter 回归通过；静态分析无问题；29 项后端接口回归通过；另启用两种字体的 34 张交互截图检查。既有 320 / 412 逻辑像素布局回归保留。

本轮没有连接安卓真机；未验证 HyperOS 实际键盘、GPU 动画性能或覆盖安装。未对生产服务执行重启、恢复或删除。配套面板 v0.39.60 仅补齐订阅编辑所需的 subscriptionId / nodes 响应字段；不直接部署线上服务。
