# 实施计划：v0.11.1 全新系统实机验收与多设备清退修复

## 目标

在全新 Ubuntu 24.04 上用不可变 `v0.11.0` 一键安装包完成真实部署验收；修复实测发现的多设备账号在超额、禁用或删除后只断开一个连接的问题，并重新完成发布、覆盖部署和真实回归。

## 已确认问题

- Hysteria 2.12.1 的 `/kick` 会为用户名设置一个可消费标记；同一用户名有多个客户端实例时，一次调用只会在下一次流量发生时断开其中一个实例。
- 当前 `UsageManager` 把超额账号永久加入 `quota_kicked`，后续不再调用 `/kick`，导致其余实例仍可继续传输。
- 禁用或删除账号也只即时调用一次 `/kick`，同样不能可靠清退全部在线实例。

## 不变量

- 不改变分享 URI、用户 token 派生、HMAC key、TLS 证书与私钥格式。
- 默认设备限制仍为 3，超限时仍只拒绝第 4 个实例，不影响前三个。
- 认证、统计接口继续只监听回环；出站策略仍默认 `web`。
- 不新增第三方依赖，不修改系统防火墙。
