# 实施计划：节点控制第二阶段

## 阶段 1：可信节点状态

- 增加管理员公钥指纹核验、撤销与心跳 nonce 数据合同。
- 心跳验收使用短时间窗、来源 IP 和原子防重放。

检查点：验证、签名失败、重放、过期、撤销和 IP 绑定测试通过。

## 阶段 2：HTTP 与控制台切片

- 管理员验证/撤销保留会话和 CSRF。
- 公网心跳保持 HTTPS-only、8 KiB 上限和稳定 JSON 错误。
- 节点列表显示指纹、验证和在线状态。

检查点：HTTP/CSRF/XSS 测试和响应式浏览器验证通过。

## 阶段 3：签名心跳 Agent

- Agent 用本地 Ed25519 私钥签署规范化心跳。
- 受签名安装器增加隔离的激活模式与 systemd timer。
- unit 不开放端口，不安装 Hysteria，不读取面板或用户秘密。

检查点：Agent/安装器合同与真实 Ed25519 签名验证通过。

## 阶段 4：发布与真实服务器验收

- 全量质量门、PR/main/tag CI、六平台矩阵和 Sigstore 发布。
- 先升级控制面，再验证新服务器签名心跳与 150 秒在线状态。
- 复核 351 用户和全部 Hysteria/DNS 身份不变量。
