# 实施计划：节点对接第一阶段

## 阶段 1：安全注册合同

- 数据库新增节点与一次性令牌结构。
- 注册服务负责输入校验、摘要存储、原子消费和状态迁移。
- 对外合同固定为管理员创建/撤销与 Agent 注册三个入口。

检查点：数据库并发、过期、撤销、IP 绑定及错误响应测试通过。

## 阶段 2：控制台切片

- 服务控制按钮区增加“对接节点”。
- 弹窗支持名称、可选公网 IP、有效期、生成/复制/撤销和节点状态列表。
- 页面继续使用现有设计系统与事件委托。

检查点：HTTP/CSRF/XSS 测试和桌面/手机浏览器验证通过。

## 阶段 3：待验证 Agent

- 增加仅执行注册的 Python Agent。
- 受签名 `install.sh --join-node` 安装 Agent、生成本地 Ed25519 身份并注册。
- 生成代码固定正式版本并校验 Cosign/Sigstore 身份。

检查点：安装器合同、Agent 集成测试和篡改/重放失败测试通过。

## 阶段 4：质量门与身份复审

- 全量单元/集成测试、Python/Bash、Ruff、Bandit、ShellCheck。
- 对比 Hysteria TLS、HMAC、URI、DNS 和服务写路径，证明第一阶段未触碰。
- 原子提交；不推送、不发布、不部署，除非用户继续授权。
