# Hysteria2管理 Android App

这是 Hysteria2-panel 同仓库维护的 Android 管理客户端，applicationId 为 `vip.ssrvpn.hysteria2manager`。

正式 APK 只包含现代 Android 手机普遍使用的 64 位 ARM（`arm64-v8a`）机器码，不支持 32 位 ARM、x86 手机或模拟器。这样可以避免在一个安装包里重复携带三套 Flutter 引擎，显著减少下载体积。

## 当前能力（v0.5.8）

- 五个统一导航页面：总览、节点管理、用户管理、订阅管理、设置。深蓝卡片、青色实时数据和紫色操作入口对齐移动渲染稿。
- 总览使用紧凑统计、实时流量和节点预算卡。节点默认展开，用户支持行内展开；用户区分普通与专线。
- 用户新增、编辑、有效期、设备限制、流量详情、域名 TOP10、批量操作与固定订阅管理。
- 节点对接、对接码管理、资源监测、预算、专线配置与需确认的运维操作。
- 默认订阅节点、外部节点的编辑/预览/发布；读取失败不允许发布，离开未保存草稿需确认。
- 单用户节点编辑需要服务端订阅响应提供 `subscriptionId` 与 `nodes`。旧面板显示升级提示，保留已有订阅启停、复制等能力，不将缺失数据显示为零节点。
- 设置提供服务控制、网络设置、备份恢复、面板更新、App 检查更新、登录管理与外观设置。
- 弹窗统一样式；输入框分隔、长表单滚动、键盘避让、安全区和大字布局。测试覆盖 1200×2608、3×密度模拟视口和窄屏；不替代真机验证。
- 登录凭据安全存储、会话失效恢复、跨账号旧请求隔离；危险写操作不自动重放。

域名 TOP10，用户页可查看全部用户合计 TOP10；两者都按上传与下载流量合计排序。
- 每个用户的详情页并列提供“最常访问”和“流量详情”入口：前者显示原域名 TOP10，后者显示本月每日用量与占比，展开日期查看 24 小时记录。按北京时间统计，日占本月、小时占当天；月初清理，仅显示功能启用后采集的数据。需要面板 v0.39.32 或更新版本。
- 节点页同时显示面板本机与远程节点，远程节点保留“一键对接、一键断连、删除对接”；在线断连负责远端清理，删除对接用于无法连接的节点。DNS 由管理员手工设置；底部按 5 秒采样展示每台服务器的实时流量。
- 设置页支持退出登录、检查 GitHub APK 更新、主题模式和强调色；“高级管理”在浏览器打开当前面板，访问订阅配置、备份与恢复等完整网页功能（浏览器需单独登录，不传递 App 凭据）。
- 全局界面遵循 Apple Design 的层级与反馈原则：系统字体、紧凑标题栏、浅色／深色磨砂卡片、统一半透明底栏与弹层。静态渐变衬底与分组背景模糊提供玻璃质感，统计卡片和外观选项适配系统大字体，高对比度模式下使用不透明材质。保留 Android 原生返回、滚动与触控反馈。

域名 TOP10 来自 Hysteria 活动 TCP 流的定时采样，是用于判断流量构成的近似统计。App 和面板不保存完整 URL、访问时间明细、请求内容或 Cookie，也无法把未出现在采样中的短连接或 UDP/QUIC 目标还原成完整浏览记录。

## 固定签名构建

正式包必须使用同一密钥。构建机从 `android/signing.properties` 读取密钥位置、别名和密码；该文件已被 Git 忽略。首次配置可参考 `android/signing.properties.example`。

```bash
flutter build apk --release --target-platform android-arm64
```

版本名和构建号读取 `pubspec.yaml` 的 `version`，构建前应先按发布计划更新该值。

每次更新必须同时满足：

1. applicationId 保持 `vip.ssrvpn.hysteria2manager`。
2. 使用同一个发布密钥。
3. `versionCode` 高于已安装版本。
4. APK Release 资产命名为 `Hysteria2-Manager-vX.Y.Z.apk`，App 才能自动发现更新。
5. APK 内只能出现 `arm64-v8a` native 库；线上工作流会在上传前拒绝其他 ABI。

发布密钥或密码一旦丢失，将无法覆盖更新已经安装的 App；应把密钥和本地签名配置放入受控的离线备份。

重装开发电脑时，可按[开发与发布恢复](../docs/DEVELOPER_RECOVERY.md)从 GitHub 持久加密备份恢复原发布身份，再生成适合新路径的本地签名配置。

## v0.4.0 外观升级

网络运行主卡、优先展示的流量预算、共享纹理的液态玻璃卡片与导航，支持深浅主题、大字和减少动画。详见[设计说明](../docs/mobile-design.md)。正式包延续既有签名，可覆盖安装；调试包使用独立标识，不覆盖正式客户端。

## v0.5.0

同步普通/专线用户、固定订阅和有效期管理，以及带类型的节点对接与端口跳跃。正式签名及应用 ID 不变，构建号升级为 36。

## v0.5.7 正式发布

首次配套面板 v0.39.62，v0.39.65 延续该移动 API。普通与专线用户卡片支持八项管理操作，操作前校验用户名与版本，并修复设置页外观按钮重叠。

## v0.5.6 正式发布

与面板 v0.39.60 配套发布，服务端补齐单用户订阅编辑需要的节点明细和订阅 ID。沿用仓库现有的标签校验、固定 Android 签名、CI 与安装器签名发布流程；APK 资产为 `Hysteria2-Manager-v0.5.6.apk`。
