# Hysteria2管理 Android App

这是 Hysteria2-panel 同仓库维护的 Android 管理客户端，applicationId 为 `vip.ssrvpn.hysteria2manager`。

正式 APK 只包含现代 Android 手机普遍使用的 64 位 ARM（`arm64-v8a`）机器码，不支持 32 位 ARM、x86 手机或模拟器。这样可以避免在一个安装包里重复携带三套 Flutter 引擎，显著减少下载体积。

## 当前能力

- 首次打开时由用户自行填写面板 HTTPS 地址、端口、管理员账号和密码；APK 不内置任何生产面板入口。密码不保存，刷新令牌进入 Android 安全存储，退出登录会清除已保存的入口和账号。
- 恢复登录时遇到超时、临时服务器故障或异常响应，会保留本机刷新令牌；网络恢复后可通过页面重试继续连接。仅当面板明确返回登录失效时清除令牌并要求重新登录。
- 退出登录或切换账号后，旧请求不会恢复旧会话或覆盖新账号；迟到的请求失败会显示状态已变化，写操作不会被自动重放到另一个账号或面板。
- 底栏包含首页、用户、节点和设置。
- 首页显示服务状态、包含面板本机的节点摘要、节点预算、服务控制和系统资源；系统资源卡可二次确认后排队重启服务器。
- 用户页不分页，默认按网页端的新增倒序显示；选择下拉项后可按流量、在线设备或用户名排序，并支持完整用户操作。
- 用户详情可查看该用户本月访问域名 TOP10，用户页可查看全部用户合计 TOP10；两者都按上传与下载流量合计排序。
- 节点页同时显示面板本机与远程节点，远程节点保留“一键对接、一键断连、删除对接”；在线断连负责远端清理，删除对接用于无法连接的节点。DNS 由管理员手工设置；底部按 5 秒采样展示每台服务器的实时流量。
- 设置页支持退出登录、检查 GitHub APK 更新、主题模式和强调色。
- 全局界面使用原生 Flutter 实现的液态玻璃视觉：动态强调色背景、半透明高光卡片与独立定位的模糊悬浮底栏；底栏为圆角屏预留安全距离，圆角外透明，弹窗、下拉菜单和二级详情页共享玻璃样式，长用户列表继续使用轻量透明材质避免掉帧。

域名 TOP10 来自 Hysteria 活动 TCP 流的定时采样，是用于判断流量构成的近似统计。App 和面板不保存完整 URL、访问时间明细、请求内容或 Cookie，也无法把未出现在采样中的短连接或 UDP/QUIC 目标还原成完整浏览记录。

## 固定签名构建

正式包必须使用同一密钥。构建机从 `android/signing.properties` 读取密钥位置、别名和密码；该文件已被 Git 忽略。首次配置可参考 `android/signing.properties.example`。

```bash
flutter build apk --release --target-platform android-arm64
```

版本名和构建号读取 `pubspec.yaml` 的 `version`，构建前应先按发布计划更新该值。

每次更新必须同时满足：

1. applicationId 保持 `vip.ssrvpn.hysteria2manager`。
2. 使用同一个发布密钥。
3. `versionCode` 高于已安装版本。
4. APK Release 资产命名为 `Hysteria2-Manager-vX.Y.Z.apk`，App 才能自动发现更新。
5. APK 内只能出现 `arm64-v8a` native 库；线上工作流会在上传前拒绝其他 ABI。

发布密钥或密码一旦丢失，将无法覆盖更新已经安装的 App；应把密钥和本地签名配置放入受控的离线备份。
